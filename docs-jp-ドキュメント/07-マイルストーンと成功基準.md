# 7. マイルストーンと成功基準

AURORAは、トレジャリー引出しガバナンス・アクションの承認と発効、およびFairwayによる初回の実装報酬の受領後、約5か月にわたる4つのマイルストーンで提供する。

各マイルストーンは、独立して審査できる具体的な公共成果物に結び付く。Fairwayが提案全体の統合的な遂行に責任を負い、必要に応じてコンソーシアムの協力者やアドバイザーの技術貢献を組み込む。

| マイルストーン | 時期 | ADA配分 | 主な成果 |
| --- | --- | ---: | --- |
| M1：仕様・アーキテクチャ | 1か月目 | **140,000** | 中核標準と実装アーキテクチャを確定 |
| M2：中核機能の構築 | 2～3か月目 | **320,000** | 発見、検証、インデックス化、フィルタリング、API基盤がテストネットで稼働 |
| M3：統合・技術デモンストレーション | 4か月目 | **290,000** | リファレンス実装、開発者ツール、テストネット上の一連の処理を実証 |
| M4：独立レビュー・公開 | 5か月目 | **190,000** | 独立レビューを完了し、最終的なオープンソース基盤を公開 |
| **合計** | **約5か月** | **940,000** | |

## M1：仕様・アーキテクチャ

**時期：** 1か月目

**ADA配分：140,000 ADA**

### 主要成果

- メタデータ標準。
- 検証フレームワーク仕様。
- AURORAディスカバリーエンジンのアーキテクチャ。
- 発見・フィルタリング仕様。
- 資本提供者プロファイル標準。
- 初期のAPI、クエリ、実装アーキテクチャ。

技術レビューには、資本提供者との相互運用性、融資リクエストUTxO設計、eUTxO固有の信用市場アーキテクチャに関連する分野で、Sundialの貢献とFallen Icarusのアーキテクチャに関する助言を含めることができる。

### 完了基準

- 中核仕様とアーキテクチャ文書を公開リポジトリで公開する。
- 互換性のある融資リクエストUTxOをインデックス化、発見、フィルタリングし、検証情報に関連付ける方法をアーキテクチャで定義する。
- 仕様はプロトコルに依存せず、単一の検証提供者、融資実装、ホステッドAURORAサービスの運用者を必須としない。
- 完成した成果物へのリンクを含む公開マイルストーン報告を公表する。

## M2：中核機能の構築

**時期：** 2～3か月目

**ADA配分：320,000 ADA**

### 主要成果

- テストネットで稼働するAURORAディスカバリーエンジン。
- 検証フレームワークの実装。
- インデックス化、発見、フィルタリング機能。
- オープンAPIの実装。
- 初期の開発者ツールと技術文書。

### 完了基準

- AURORAが、テストネット上の互換融資リクエストUTxOと関連メタデータを識別・インデックス化できる。
- 公開APIが、公開されたメタデータ基準でインデックス化済み機会を取得・フィルタリングできる。
- 検証情報を、検証フレームワークを通じて公開・評価できる。
- ディスカバリーエンジンを、FairwayがホストするAPIに依存せずテスト環境へ展開できる。
- ソースコードとマイルストーン文書を公開する。

## M3：統合・技術デモンストレーション

**時期：** 4か月目

**ADA配分：290,000 ADA**

### 主要成果

- リファレンス実装。
- リファレンスクエリライブラリ。
- 資本提供者向けフィルタリングの統合。
- 市場発見APIの統合。
- 軽量な統合例と開発者ツール。
- 開発者向け文書と統合文書。
- テストネット上の一連の処理を通した技術デモンストレーション。

### 完了基準

- リファレンス実装で、互換融資リクエストUTxOへの標準メタデータの付加、インデックス化、発見、フィルタリング、検証情報との関連付けを実証する。
- 公開リファレンスクエリにより、資本提供者の要件を発見・フィルタリング基準へ変換する方法を示す。
- 技術的能力を持つ第三者が、公開API、ツール、文書を用いて主要な処理フローを再現できる。
- 公開マイルストーン報告を公表する。

## M4：独立レビュー・公開

**時期：** 5か月目

**ADA配分：190,000 ADA**

セキュリティ、法務、文書に関する作業がプロジェクト日程を不必要に延ばさないよう、独立レビューの準備は直前の実装マイルストーン中に開始できる。

### 主要成果

- トレジャリー資金で開発するソフトウェアと関連インターフェースの独立したセキュリティレビュー。
- 第11章に定める資金提供の仕組みと記録を対象とする、最終的な独立トレジャリー資金使用監査・監督報告。
- インフラストラクチャに限定された本提案の範囲内での独立した法務レビュー。
- 重大な指摘事項の解決、または是正内容の文書化。
- 最終版の仕様、ソフトウェア、API、ツール、リファレンス実装、文書。
- 公開リポジトリ、ビルド手順、運用文書。
- 最終プロジェクト報告。

### 完了基準

- 必須の独立レビューを完了し、公開に影響する重大な指摘に対応するか、その内容を明確に文書化する。
- 独立したトレジャリー資金使用の監査・監督を完了し、最終プロジェクト報告に含める。
- トレジャリー資金で開発するすべてのソフトウェア、標準、リファレンス実装を、**Apache License 2.0**で公開する。
- 公開リポジトリに、独立した検査・運用に十分なソースコード、仕様、文書、展開手順を収録する。
- 技術的能力を持つ第三者が、公開リポジトリ、文書、展開手順を用いて、関連するAURORA基盤を展開・運用できる。
- 最終報告で、完成した公共成果物を本提案の成果物とマイルストーン要件に対応付ける。

## マイルストーンの資金提供と支払原則

マイルストーン別の配分は、実装報酬と支援費用を含む資金枠である。当初の配分は、中核実装に**800,000 ADA**、レビュー、ホスティング、トレジャリー資金使用の監督、技術予備費に**140,000 ADA**とする。第5章の再配分規定に従って調整できるが、総申請額の**940,000 ADA**を増額せず、承認済みの基盤範囲も変更しない。

各実装段階の資金は前払いする。プロジェクト開始時には、合計**140,000 ADA**までの支払いを承認する。M1の受入れ後は累積支払上限を**460,000 ADA**に、M2の受入れ後は**750,000 ADA**に、M3の受入れ後は**940,000 ADA**に引き上げる。

この上限の範囲内で、実装報酬をAURORAトレジャリー・マルチシグからFairwayが指定する実装用ウォレットへ分割して送金する。支援費用と承認済みの再配分は、別途記録する。追加の実装報酬には、第5章に基づく管理者の承認を必要とする。

受入れは、直前のマイルストーンについて公開された成果物と完了基準に基づいて判断する。Fairway内部の給与、仕入先の請求書、実際の遂行費用は、定額の実装報酬の算定基準とはしない。M4の完了に伴い、最終的な遂行報告、最終独立監査、プロジェクトの完了手続を行う。
