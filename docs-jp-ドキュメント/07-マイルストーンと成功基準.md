# 7. マイルストーンと成功基準

Auroraは約5か月、4つのマイルストーンで提供する。各マイルストーンは独立査読可能な具体的公共成果に結び付く。Fairwayが統合履行に責任を負い、必要に応じて協力者とアドバイザーの技術貢献を組み込む。

| マイルストーン | 時期 | ADA配分 | 主な成果 |
| --- | --- | ---: | --- |
| M1：仕様・アーキテクチャ | 第1月 | **150,000** | 中核標準と実装アーキテクチャを確定 |
| M2：中核構築 | 第2～3月 | **350,000** | 発見、検証、インデックス化、フィルタリング、API基盤がテストネットで稼働 |
| M3：統合・技術デモンストレーション | 第4月 | **300,000** | リファレンス実装、開発者ツール、完全なテストネット工程を実証 |
| M4：独立レビュー・公開 | 第5月 | **200,000** | 独立レビュー完了、最終オープンソース基盤公開 |
| **合計** | **約5か月** | **1,000,000** |  |

## M1：仕様・アーキテクチャ

**時期：** 第1月　**ADA配分：150,000 ADA**

### 主要成果

メタデータ標準、検証フレームワーク仕様、Auroraディスカバリーエンジン・アーキテクチャ、発見・フィルタリング仕様、資本提供者プロファイル標準、初期API・クエリ・実装アーキテクチャ。資本提供者との相互運用性、融資リクエストUTxO設計、eUTxO固有の信用市場アーキテクチャについて、SundialとFallen Icarusが必要に応じてレビューに貢献できる。

### 完了基準

- 中核仕様とアーキテクチャ文書を公開リポジトリで公開する。
- 互換融資リクエストUTxOのインデックス化、発見、フィルタリング、検証情報との関連付けを定義する。
- 単一の検証提供者、融資実装、ホステッドAurora運用者を必要とせず、プロトコル非依存性を維持する。
- 完了成果へのリンクを含む公開マイルストーン報告を公表する。

## M2：中核構築

**時期：** 第2～3月　**ADA配分：350,000 ADA**

### 主要成果

テストネットで稼働するAuroraディスカバリーエンジン、検証フレームワーク実装、インデックス化・発見・フィルタリング、オープンAPI、初期開発者ツール・技術文書。

### 完了基準

- Auroraがテストネット上の互換融資リクエストUTxOと関連メタデータを識別・インデックス化できる。
- 公開APIが公開メタデータ基準で機会を取得・フィルタリングできる。
- 検証情報を検証フレームワークで公開・評価できる。
- FairwayホステッドAPIに依存せずテスト環境へ展開できる。
- ソースコードとマイルストーン文書を公開する。
- 独立したCardanoトレジャリー資金使用に関する中間支出・照合レビューを完了し、公表する。

## M3：統合・技術デモンストレーション

**時期：** 第4月　**ADA配分：300,000 ADA**

### 主要成果

リファレンス実装、リファレンスクエリライブラリ、資本提供者向けフィルタリング統合、市場発見API統合、軽量統合例・開発者ツール、開発者・統合文書、エンドツーエンドのテストネット技術デモンストレーション。

### 完了基準

- 互換融資リクエストUTxOが標準メタデータで拡充され、インデックス化、発見、フィルタリングされ、検証情報に関連付けられることを示す。
- 公開リファレンスクエリが、資本提供者要件を発見・フィルタリング基準へ変換する方法を示す。
- 技術能力を有する第三者が、公開API、ツール、文書で主要工程を再現できる。
- Cardanoトレジャリー資金による融資原資、借り手展開、法定通貨決済、商用融資実行を必要としない。
- 公開マイルストーン報告を公表する。

## M4：独立レビュー・公開

**時期：** 第5月　**ADA配分：200,000 ADA**

セキュリティ、法務、文書作業が日程を不必要に延ばさないよう、独立レビューの準備は直前の実装マイルストーン中に開始できる。

### 主要成果

対象ソフトウェア・インターフェースの独立セキュリティレビュー、承認範囲・マイルストーン上限との照合を含む独立したCardanoトレジャリー資金使用の監査・監督報告、インフラストラクチャに限定した独立法務レビュー、重大な指摘の解決または是正記録、最終仕様・ソフトウェア・API・ツール・リファレンス実装・文書、公開リポジトリ・ビルド手順・運用文書、最終報告。

### 完了基準

- 必須の独立レビューを完了し、公開に影響する重大な指摘を対処または透明に記録する。
- 独立した資金使用の監査・監督を完了し最終報告に含める。
- すべての対象成果を**Apache License 2.0**で公開する。
- 独立検査・運用に十分なソース、仕様、文書、展開手順を公開する。
- 技術能力を有する第三者がFairway、Sundial、個人アドバイザーに依存せず運用できる。
- 最終報告で公共成果を提案成果物・マイルストーン要件に対応付ける。

## マイルストーン支出原則

配分額は実装の進行に伴う累積支出上限である。開始時はM1の**150,000 ADA**までを承認し、M1承認後は累積**500,000 ADA**、M2承認後は累積**800,000 ADA**、M3承認後は全額**1,000,000 ADA**へ引き上げる。M4完了により最終照合・報告を行う。

Fairwayは統合履行に責任を負い、Auroraトレジャリー管理者は次の支出上限を承認する前に公開マイルストーン証拠を審査する。
