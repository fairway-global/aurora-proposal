# 4. 成果物

本プロジェクトは、将来のCardano信用市場実装が独立して採用、拡張、運用できるオープンソースの市場インフラストラクチャを提供する。

Cardanoトレジャリー資金は、独立した融資リクエストUTxOを発見、フィルタリング、検証でき、機関が利用可能なものにするための標準、ソフトウェア、リファレンス実装、文書および技術的検証に充当する。融資原資、商用オンボーディング、実融資の実行には充当しない。

## 中核インフラストラクチャ成果物

1. **メタデータ標準。**
   信用市場機会と融資リクエストUTxOに関連するメタデータ参照を記述する、版管理されたオープン仕様。基礎となる融資プロトコルを変更せずに、機関に関連する情報を一貫して付加する方法を定義し、融資モデル、法域、検証システムをまたいで拡張可能とする。

2. **検証フレームワーク。**
   融資リクエストUTxOに関連する機関属性、適格性、コンプライアンスその他の証明ベース情報を付加し評価する拡張可能なフレームワーク。単一の本人確認またはコンプライアンス基盤を必須とせず、複数のクレデンシャル・システム、証明システム、検証提供者に対応する。

3. **Auroraディスカバリーエンジン。**
   互換性のある融資リクエストUTxOと関連メタデータをインデックス化し、オープンAPIを通じて融資機会を公開し、発見とフィルタリングを支援し、検証情報へのアクセスを提供するとともに、互換性のある融資実装が公開する関連ライフサイクル情報を追跡するオープンソース・サービス。
   第三者の開発者がFairwayまたは単一のホステッドサービスに依存しなくて済むよう、独立運用可能とする。

4. **フィルタリングおよびクエリ機能。**
   公開されたメタデータ・スキーマおよびクエリ仕様に基づくオープンなフィルタリング機能。互換アプリケーションと資本提供者は、法域、期間、資産、案件規模、検証要件その他、該当スキーマが対応する標準属性に従って機会を特定できる。

5. **オープンAPI。**
   Aurora互換の信用機会、関連メタデータ、検証情報および関連ライフサイクル情報を照会する公開インターフェース。
   プロトコル固有の統合作業を減らし、ウォレット、融資アプリケーション、分析サービスその他のエコシステム参加者が共通市場インフラストラクチャ上に構築できるようにする。

6. **開発者ツールおよびリファレンス実装。**
   Aurora互換メタデータの作成、融資リクエストUTxOの識別とインデックス化、ディスカバリーエンジンへの照会、フィルタリング基準の適用、検証参照の評価方法を示すオープンなツールとリファレンスコード。
   単一の融資プロトコルまたは商用展開モデルの採用を求めず、インフラストラクチャの全工程を実証する。

7. **文書。**
   メタデータ標準、検証フレームワーク、ディスカバリーエンジン、API、フィルタリング・モデルおよびリファレンス実装を網羅する技術文書。
   第三者開発者が標準を採用し、関連インフラストラクチャを独立運用するために十分な統合・運用ガイダンスを含む。

## 資本発見・配分レイヤー

Auroraには、Aurora全体の実装における資本提供者の要件、発見、フィルタリングおよび相互運用性に関するSundialの限定的な技術貢献が含まれる。

その貢献は次のとおりである。

**資本提供者プロファイル標準。** 法域、案件規模、期間、資産、検証要件、リスク選好等の要件を表現するオープン・スキーマ。

**発見・フィルタリング仕様。** 資本提供者の要件を、Aurora互換の信用機会に対する発見・フィルタリング基準へ変換する方法を記述する公開仕様。

**リファレンスクエリライブラリ。** 潜在的な資本提供者と互換アプリケーションが公開標準を用いて機会を照会・フィルタリングする方法を示すオープンな例。

**市場発見APIへの貢献。** Auroraインフラストラクチャを通じ、資本提供者に関連する発見・フィルタリング機能を公開するために必要なAPI定義と関連実装への貢献。

**軽量な統合成果物。** 外部アプリケーションが資本提供者プロファイル標準とクエリ仕様を統合する方法を示すリファレンス例または軽量SDKコンポーネント。

**文書。** 第三者がSundialに依存せず、関連標準およびインターフェースを利用、実装、拡張するために十分な技術文書。

これらは、Sundialの別製品または独立採算の作業系統ではなく、Aurora共通のオープンソース・インフラストラクチャを構成する。Sundialは該当分野の技術的専門知識を提供し、Fairwayは主任実装者として提案全体の統合的な履行に責任を負う。

資本発見・配分レイヤーは、Cardanoトレジャリー資本の配分、融資判断、専有的な資本配分商品の作成を行わない。将来の市場参加者が各自の要件に従って利用できるオープン標準とリファレンスツールを提供する。

## 技術デモンストレーション

中核インフラストラクチャが意図どおり連携することを示すテストネット上の技術デモンストレーションを実施する。互換性のある融資リクエストUTxOが、(1)互換融資インフラストラクチャで作成され、(2)標準メタデータで拡充され、(3)Auroraディスカバリーエンジンに識別・インデックス化され、(4)オープンAPIで発見され、(5)公開基準でフィルタリングされ、(6)検証フレームワークで評価可能な検証情報に関連付けられ、(7)互換リファレンス・アプリケーションまたはクエリ工程により利用されることを示す。

これは商用融資実績ではなくインフラストラクチャを検証するものであり、Cardanoトレジャリー資金による融資原資、法定通貨決済、借り手への支払、SACCOへの実融資を必要としない。

## セキュリティおよび法務レビュー

提供インフラストラクチャに適した独立レビューを対象範囲に含む。セキュリティレビューは最終公開前にCardanoトレジャリー資金によるソフトウェアと関連技術インターフェースを評価する。法務レビューは本提案の範囲内でオープンなインフラストラクチャ、標準、想定運用モデルを評価するが、将来の融資活動または商用展開を法的に承認するものではなく、それらは関係参加者の責任に属する。
