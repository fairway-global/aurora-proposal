# 4. 成果物

本プロジェクトは、Cardanoの共通信用市場を支えるオープンソース基盤を提供する。

トレジャリー資金は、独立した融資リクエストUTxOを、互換性のある信用市場アプリケーションを横断して発見、フィルタリング、検証し、評価しやすくするための標準、ソフトウェア、リファレンス実装、文書、技術的検証に充当する。

## 中核インフラストラクチャ成果物

1. **メタデータ標準。**
   信用市場の機会と融資リクエストUTxOに関連するメタデータ参照を記述する、版管理されたオープン仕様。基礎となる融資プロトコルを変更せずに、機関にとって重要な情報を一貫して付加する方法を定める。融資モデル、法域、検証システムを横断して拡張可能とする。

2. **検証フレームワーク。**
   融資リクエストUTxOに関連する機関属性、適格性、コンプライアンス、その他の証明ベースの情報を付加・評価する拡張可能な枠組み。単一の本人確認基盤やコンプライアンス基盤を必須とせず、複数のクレデンシャル・システム、証明システム、検証提供者に対応する。

3. **Auroraディスカバリーエンジン。**
   互換性のある融資リクエストUTxOと関連メタデータをインデックス化し、オープンAPIを通じて融資機会を公開するオープンソース・サービス。発見とフィルタリングを支援し、検証情報へのアクセスを提供し、互換融資実装が公開する関連ライフサイクル情報を追跡する。独立した展開・運用に対応し、第三者の開発者向けにインターフェースと運用文書を公開する。

4. **フィルタリング・クエリ機能。**
   公開されたメタデータ・スキーマとクエリ仕様に基づくオープンなフィルタリング機能。互換アプリケーションと資本提供者は、法域、期間、資産、案件規模、検証要件、その他の該当スキーマが対応する標準属性に従って機会を特定できる。

5. **オープンAPI。**
   Aurora互換の信用機会、関連メタデータ、検証情報、関連ライフサイクル情報を照会する公開インターフェース。プロトコル固有の統合作業を減らし、ウォレット、融資アプリケーション、分析サービス、その他のエコシステム参加者が共通市場基盤を利用して開発できるようにする。

6. **開発者ツールとリファレンス実装。**
   Aurora互換メタデータの作成、融資リクエストUTxOの識別・インデックス化、ディスカバリーエンジンへの照会、フィルタリング基準の適用、検証参照の評価方法を示すオープンなツールとリファレンスコード。リファレンス実装では、単一の融資プロトコルや商用展開モデルの採用を求めず、基盤の一連の処理を実証する。

7. **文書。**
   メタデータ標準、検証フレームワーク、ディスカバリーエンジン、API、フィルタリング・モデル、リファレンス実装を対象とする技術文書。第三者の開発者が標準を採用し、関連基盤を独立して運用できるよう、十分な統合・運用ガイダンスを含める。

## 資本ディスカバリーレイヤー

Auroraには、資本提供者の要件、発見、フィルタリング、相互運用性に関する、Sundialによる特定領域の技術貢献が含まれる。これらはAurora全体の実装の一部を構成する。

具体的な成果は次のとおりである。

**資本提供者プロファイル標準。** 法域、案件規模、期間、資産、検証要件、リスク選好などの要件を表現するオープン・スキーマ。

**発見・フィルタリング仕様。** 資本提供者の要件を、Aurora互換信用機会に対する発見・フィルタリング基準へ変換する方法を記述する公開仕様。

**リファレンスクエリライブラリ。** 将来の資本提供者と互換アプリケーションが、公開標準を使って機会を照会・フィルタリングする方法を示すオープンな例。

**市場発見APIへの貢献。** Aurora基盤を通じて資本提供者向けの発見・フィルタリング機能を公開するために必要なAPI定義と関連実装への貢献。

**軽量な統合成果物。** 外部アプリケーションが資本提供者プロファイル標準とクエリ仕様を統合する方法を示すリファレンス例、または軽量SDKコンポーネント。

**文書。** 第三者がSundialに依存せず、関連する標準とインターフェースを利用、実装、拡張できるだけの技術文書。

これらは、Sundialの別製品や別途資金提供を受ける作業ではなく、Aurora共通のオープンソース基盤の一部である。Sundialは関連分野の専門知識を提供し、Fairwayは主導実装者として提案全体の統合的な遂行に責任を負う。

資本ディスカバリーレイヤーは、トレジャリー資本の配分、融資判断、独自の資本配分商品の作成を行わない。将来の市場参加者が各自の要件に従って利用できるオープン標準とリファレンスツールを提供する。

## 技術デモンストレーション

プロジェクトでは、Auroraの中核構成要素がどのように連携して動作するかを示すテストネット上の技術デモンストレーションを実施する。

互換性のある融資リクエストUTxOについて、次の一連の処理を示す。

1. 互換性のある融資インフラストラクチャを通じて作成する。
2. 標準化されたメタデータを付加する。
3. Auroraディスカバリーエンジンが識別し、インデックス化する。
4. オープンAPIを通じて発見する。
5. 公開された基準に従ってフィルタリングする。
6. 検証フレームワークで評価可能な検証情報に関連付ける。
7. 互換リファレンス・アプリケーションまたはクエリ処理で利用する。

デモンストレーションでは、融資リクエストUTxOの作成とメタデータの付加から、発見、フィルタリング、検証、アプリケーションでの利用まで、**基盤全体の動作と相互運用性**を検証する。

## セキュリティ・法務レビュー

資金対象の範囲には、提供するインフラストラクチャに適した独立レビューを含める。

セキュリティレビューでは、最終公開前に、トレジャリー資金で開発するソフトウェアと関連技術インターフェースを評価する。

法務レビューでは、本提案の範囲内で、オープンなインフラストラクチャ、標準、文書、想定する運用モデルを評価する。

## オープンソース公開と公開文書

トレジャリー資金で開発するすべてのソフトウェア、標準、リファレンス実装は、**Apache License 2.0**で公開する。

公開リポジトリには、第三者が基盤を検査、運用、変更、拡張するために必要なソースコード、仕様、文書、実装資料を収録する。

承認済みのマイルストーンと成果物に対する公開進捗報告も行う。

成果となるインフラストラクチャは、将来の開発者がFairway、Sundial、特定の融資実装を利用するかどうかにかかわらず、Cardanoエコシステムで引き続き利用できる。
