# 6. コンソーシアムと関連実績

Auroraは、Fairwayが主導する統合実装として提供する。Sundialが技術的に貢献し、必要に応じて専門家から助言を受ける。

Fairwayは、資金対象となる作業全体の遂行、調整、統合に責任を負う。Sundialは、特定のオープンソース標準、相互運用性の要件、リファレンス実装について、補完的な技術的専門知識を提供する。Fallen Icarus (Rusty)は、基礎となる取引ベースの信用市場アーキテクチャに関する技術アドバイザー兼レビュー担当者としてプロジェクトを支援する。

トレジャリーは、組織別の個別作業ではなく、成果となるAurora基盤と公共成果物に資金を提供する。

本実装には、CardanoとMidnightの基盤、検証システム、eUTxOベースの信用市場、機関金融、オープンな技術標準に関する経験を結集する。これにより、信用機会をオンチェーンで一貫して表現・公開することと、その情報を将来のアプリケーションや資本提供者に有用なインターフェースで発見・フィルタリング・評価できるようにすることの両面に対応できる。

## Fairway

FairwayはAuroraの実装を主導し、プロジェクトを調整する。

私たちの経験は、技術スタックの単一領域にとどまらない。CardanoとMidnightの基盤、機関との統合、検証システム、ゼロ知識証明、クレデンシャル・スキーマの設計に取り組んできた。これらのプロジェクトに共通する課題は、相互運用性を実現するために十分に実用的でありながら、各アプリケーションが独自の技術やポリシーを選べる柔軟性を持つ標準を、どのように定めるかという点である。

これは、Auroraが取り組む問題に極めて近い。メタデータ標準、検証フレームワーク、ディスカバリーエンジンはいずれも、市場を単一の融資プロトコル、証明システム、法域に結び付けることなく、信用機会を記述・照会する共通構造を必要とする。

また、エチオピアのFayda国民IDシステム、Cardanoのクレデンシャル基盤、高等教育の資格証明に関する取り組みなど、実際の機関が参加するCatalyst助成プロジェクトを実施してきた。

実績資料：[Atala PRISMを活用した採用（Project Catalyst）](https://projectcatalyst.io/funds/8/accelerate-decentralized-identity/recruitment-utilizing-atala-prism)、[エチオピアの国民IDシステムの活用（Project Catalyst）](https://projectcatalyst.io/funds/12/cardano-use-cases-concept/leveraging-national-id-system-in-ethiopia-for-more-scalable-adoption-of-cardano-in-identity-solutions)、[Fund 12のマイルストーン記録](https://milestones.projectcatalyst.io/projects/1200143/milestones)。

最近では、Midnightや他のブロックチェーン環境で、ゼロ知識技術を用いたプライバシー保護型検証システムを構築・検証してきた。その過程で、複数の製品や統合先で利用できる必要がある証明フロー、メタデータ、スキーマを直接扱ってきた。

Fairwayは数年にわたり、機関市場がパブリック・ブロックチェーン基盤をどのように利用できるかという、より広い課題にも取り組んでいる。特に、コンプライアンスに対応したDeFi、本人確認、信用の分野で経験を重ねてきた。Auroraの設計思想の多くは、この取り組みから生まれた。

**関連資料：** [Fairwayのインサイト記事](https://fairway.global/insights.html)

Auroraでは、標準、ディスカバリーエンジン、検証レイヤー、API、開発者ツール、文書を含む各技術領域の、全体アーキテクチャ、実装、統合にFairwayが責任を負う。

トレジャリー資金で開発するすべてのソフトウェア、標準、リファレンス実装は、**Apache License 2.0**で公開する。

## Sundial

Sundialは、機関向け信用基盤、Bitcoinを基盤とする金融、資本提供者との相互運用性が交わる分野で補完的な専門知識を提供する、技術コンソーシアム協力者である。

Sundial Protocolは、Cardano上でBitcoin向け金融基盤を開発している。チームにはテストネットの運用実績があり、Hackenによる第三者セキュリティ監査を完了している。また、Paris Blockchain Weekの機関向け部門で第1位を獲得した。

Auroraでは、専門知識が直接関連する次のオープンソース構成要素に技術的な意見を提供する。

- 資本提供者プロファイル標準。
- 発見・フィルタリング仕様。
- リファレンスクエリライブラリ。
- 市場発見APIの設計。
- 軽量な統合例と関連技術成果物。
- 関連標準・インターフェースを横断した資本提供者との相互運用性のレビュー。

これらの貢献は、別のプラットフォームや独立して資金提供を受ける製品としてではなく、Aurora共通の技術成果物に組み込む。

Aurora実装の他の部分と同様に、本提案を通じて開発する技術成果は、プロジェクトのオープンソースの確約に従い、将来のCardano開発者や互換融資実装が同等の条件で利用できる。

## 技術アドバイザー：Fallen Icarus (Rusty)

Fallen Icarus (Rusty)はAuroraの技術アドバイザーとして、Cardanoの取引ベースの信用市場モデルと融資リクエストUTxO設計について、アーキテクチャのレビューと分野固有の専門知識を提供する。

Rustyは、オープンソースの**cardano-loans**プロトコル、およびUTxOベースの状態管理とビーコントークンによる発見を用いる、関連するCardanoのピアツーピアDeFiアーキテクチャの主要貢献者である。cardano-loansのリポジトリには、融資リクエスト、オファー、実行中の融資が別々のUTxOとして存在し、ビーコントークンによって発見可能となるピアツーピア融資モデルが記載されている。この経験は、独立して発見可能な信用機会をAuroraが扱ううえで直接関連する。

実績資料：[fallen-icarus/cardano-loansリポジトリ](https://github.com/fallen-icarus/cardano-loans)、[cardano-loansのリリース記録](https://github.com/fallen-icarus/cardano-loans/releases)。

助言には、次の内容が含まれ得る。

- 信用市場アーキテクチャのレビュー。
- 融資リクエストUTxOの設計上の検討事項。
- eUTxO固有の実装上の検討事項。
- 関連する標準と技術インターフェースのレビュー。
- Auroraの発見・メタデータ・検証基盤と、基礎となる取引ベースの信用市場モデルとのアーキテクチャ上の整合性。

Rustyの関与は、基礎となる信用アーキテクチャと、Auroraが開発するオープン市場基盤との技術的な連続性を強化する。

## 統合された遂行能力

この実装体制は、市場基盤、資本提供者との相互運用性、eUTxO信用アーキテクチャにまたがる、相互補完的な能力を組み合わせる。

Fairwayは、実装の主導、システム統合、検証、市場基盤の開発を担う。Sundialは、資本提供者の要件をどのように表現・照会し、オープンな信用市場基盤に統合すべきかについて、専門的な技術的視点を提供する。Rustyは、基礎となる取引ベースの信用市場モデルに関して、アーキテクチャ上の連続性と技術レビューを提供する。

これらの能力を組み合わせ、融資リクエストUTxOを公開・インデックス化するCardano開発者と、機会を発見・フィルタリング・評価する将来のアプリケーションや資本提供者の、双方の視点で機能する実装を支える。

成果となる標準とソフトウェアは、独立して運用できるよう設計する。
