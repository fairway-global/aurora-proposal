# 6. コンソーシアムと関連実績

AuroraはFairwayが率いる統合実装として提供され、Sundialが技術貢献を行い、必要に応じて分野専門家が助言する。Fairwayは全体の遂行、調整、統合に責任を負い、Sundialは選定されたオープンソース標準、相互運用要件、リファレンス実装に補完的な専門知識を提供する。Fallen Icarus (Rusty)は、基礎となる取引ベースの信用市場アーキテクチャに関する技術アドバイザー兼査読者である。Cardanoトレジャリーは組織別の作業パッケージではなく、Auroraインフラストラクチャと公共成果物に資金を提供する。

実装には、CardanoおよびMidnightのインフラストラクチャ、検証システム、eUTxOベース信用市場、機関金融、オープン技術標準の経験を結集する。これにより、信用機会をオンチェーンで一貫して表現・公開する側と、将来のアプリケーションや資本提供者がそれを発見、フィルタリング、評価できる側の双方に対応する。

## Fairway

FairwayはAuroraの主任実装者兼プロジェクト調整者である。CardanoとMidnightにおける本人確認、検証、標準ベースのインフラストラクチャ、および機関システムとブロックチェーン基盤の統合経験は、メタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、オープンAPI、開発者ツール、リファレンス実装に直接関連する。

関連実績には、Catalyst資金による本人確認構想、エチオピアのFayda National IDとCardanoベースの検証可能なクレデンシャル基盤の統合、エチオピアの高等教育機関との卒業証明クレデンシャル発行がある。Project Catalystの記録は完了済みの本人確認事業とFayda実装を示し、FairwayのFund 12提案は2つの高等教育機関との提携および50件の卒業証明クレデンシャル発行を記録している。
証拠：[Recruitment Utilizing Atala PRISM — Project Catalyst](https://projectcatalyst.io/funds/8/accelerate-decentralized-identity/recruitment-utilizing-atala-prism)、[Leveraging National ID system in Ethiopia — Project Catalyst](https://projectcatalyst.io/funds/12/cardano-use-cases-concept/leveraging-national-id-system-in-ethiopia-for-more-scalable-adoption-of-cardano-in-identity-solutions)、[Fund 12 milestone record](https://milestones.projectcatalyst.io/projects/1200143/milestones)。

これらは単独のスマートコントラクト開発ではなく、クレデンシャル基盤、ブロックチェーン統合、機関参加者間の調整を要した。Auroraでは、標準、ソフトウェア、文書、レビュー、技術デモンストレーションを一体の公共インフラストラクチャ事業として提供する。主任実装者であることは成果への排他的権利を生じさせず、対象成果はApache License 2.0の下で独立利用、運用、変更、拡張できる。

## Sundial

Sundialは、機関信用インフラストラクチャ、Bitcoinネイティブ金融、資本提供者との相互運用性が交差する領域の専門性を提供する技術協力者である。Sundial ProtocolはCardano上でBitcoin志向の金融インフラストラクチャを開発し、稼働テストネットを運用し、Hackenによる第三者セキュリティ監査を完了し、Paris Blockchain WeekのInstitutional Trackで1位を獲得した。

Auroraでは、資本提供者プロファイル標準、発見・フィルタリング仕様、リファレンスクエリライブラリ、市場発見API設計、軽量統合例、関連標準・インターフェースの相互運用性レビューに技術貢献する。これらは別プラットフォームや独立資金の商品ではなく共通成果に組み込まれる。役割は技術・標準に限定され、Cardanoトレジャリー資金による資金調達、事業開発、機関関係管理、商用資本配分を前提としない。成果は同じオープンソース条件で将来の開発者に提供される。

## 技術アドバイザー — Fallen Icarus (Rusty)

Fallen Icarus (Rusty)は、Cardanoの取引ベース信用市場モデルと融資リクエストUTxO設計に関するアーキテクチャレビューおよび専門知識を提供する。Rustyはオープンソースの**cardano-loans**プロトコルと、UTxOベース状態およびビーコン・トークンによる発見を用いるCardanoのP2P DeFiアーキテクチャの主要貢献者である。同リポジトリは、融資リクエスト、オファー、実行中融資が個別UTxOとして存在し、ビーコン・トークンで発見可能となるP2P融資モデルを記載しており、Auroraに直接関連する。

証拠：[fallen-icarus/cardano-loans](https://github.com/fallen-icarus/cardano-loans)、[cardano-loans releases](https://github.com/fallen-icarus/cardano-loans/releases)。

助言には、信用市場アーキテクチャ、融資リクエストUTxO、eUTxO固有の実装、関連標準・インターフェース、基礎モデルとAuroraの発見・メタデータ・検証基盤との整合性のレビューが含まれ得る。この役割は独立資金の組織的作業パッケージ、別個の所有権、Fallen Icarusへの運用依存を生じさせない。

## 統合的な履行能力

Fairwayは主任実装、システム統合、検証、市場基盤開発を担い、Sundialは資本提供者要件の表現・照会・統合に専門的視点を、Rustyは基礎アーキテクチャとの連続性と技術レビューを提供する。これにより、融資リクエストUTxOを公開・インデックス化するCardano開発者と、それを発見・フィルタリング・評価する将来のアプリケーション／資本提供者の双方に対応する。

標準とソフトウェアは独立運用可能に設計し、Auroraの採用にFairway、Sundialまたは個人アドバイザーの継続関与は不要である。いずれの参加者にも対象成果を運用、商用化、拡張する排他的権利はない。

## 過去の履行実績

参加者は、検証、融資基盤、機関採用に関連するCatalyst事業、オープンソース基盤、ブロックチェーン統合、監査済み技術システム、エコシステム事業を履行してきた。本提案はゼロからではなく既存の経験と提供済み基盤を土台とする。過去の商業関係、助言活動、組織的構想は、成果物に明示されない限り対象範囲に含まれない。
