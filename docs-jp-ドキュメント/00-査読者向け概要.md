# 審査者向け概要

AURORAは、Cardanoの信用市場に共通のオープン基盤を約**5か月**、**4つのマイルストーン**で整備するため、**940,000 ADA**を申請する。

**開発状況：** AURORAは、本提案に基づく開発を開始できる状態にある。トレジャリー資金による開発はまだ開始していない。トレジャリー引出しガバナンス・アクションの承認と発効、およびFairwayによる初回の実装報酬の受領後に開始する。

## Cardanoトレジャリー資金の対象

互換性のある融資実装を横断して、独立した融資リクエストUTxOを記述、インデックス化、発見、フィルタリング、検証し、評価しやすくする標準とソフトウェアを構築する。

資金は、メタデータ標準、検証フレームワーク、AURORAディスカバリーエンジン、オープンAPIとフィルタリング機能、資本提供者プロファイル標準とリファレンスクエリライブラリ、開発者ツールとリファレンス実装、技術文書、独立したセキュリティ・法務レビューに充当する。最終段階では、テストネット上で一連の処理を通した技術デモンストレーションとオープンソース公開を行う。ガバナンス体制には、独立したトレジャリー資金使用の監査・監督も含まれる。

AURORAは、融資の組成、融資原資の保管、資金提供対象の決定を行わない。基礎となる融資実装が資金提供と決済を担い、AURORAは、その周囲に再利用可能な市場基盤を提供する。

## 予算

| 区分 | ADA |
| --- | ---: |
| 中核インフラストラクチャ開発（当初配分） | **800,000** |
| レビュー・ホスティング・技術予備費（当初配分） | **140,000** |
| **合計** | **940,000** |

参照価格を1 ADA当たり0.20米ドルとした参考換算額は、合計188,000米ドルである。申請通貨はADAであり、成果物は為替変動ではなく、承認済み範囲とマイルストーンの完了によって定義する。

当初の800,000 ADAは、Fairwayの内部費用を実費精算するのではなく、合意された成果物に対して支払う定額の実装報酬である。管理者は、必須レビュー、監査、既存の支払義務に必要な資金を確保した上で、承認済み範囲と総予算の枠内で、追加の実装報酬を含む再配分を承認できる。

## マイルストーンと審査証拠

| 段階 | 時期 | ADA配分 | 主な確認事項 |
| --- | --- | ---: | --- |
| M1：仕様・アーキテクチャ | 1か月目 | **140,000** | 中核仕様、アーキテクチャ、初期API・クエリ設計の公開 |
| M2：中核機能の構築 | 2～3か月目 | **320,000** | テストネットでの稼働、API・検証機能、ソースコードと文書の公開 |
| M3：統合・技術デモンストレーション | 4か月目 | **290,000** | リファレンス実装、クエリ、公開ツールと文書による主要処理の再現性 |
| M4：独立レビュー・公開 | 5か月目 | **190,000** | 必須レビュー・最終資金使用監査、Apache License 2.0での公開、第三者による展開・運用 |
| **合計** | **約5か月** | **940,000** | |

各段階の配分は、実装報酬と支援費用を含む資金枠であり、そのままFairwayへの個別支払額を意味するものではない。実装報酬はFairwayの指定ウォレットへ前払いする。累積支払上限は、開始時の**140,000 ADA**、M1受入れ後の**460,000 ADA**、M2受入れ後の**750,000 ADA**、M3受入れ後の**940,000 ADA**と段階的に引き上げる。M4では最終的な遂行報告と独立監査を実施し、完了手続を行う。各段階の正式な完了条件は[第7章](07-マイルストーンと成功基準.md)に記載する。

## 遂行体制とガバナンス

Fairwayが主導実装者兼調整者、Sundialが技術協力者、Fallen Icarus (Rusty)が技術アドバイザー兼アーキテクチャのレビュー担当者を務める。

トレジャリー引出しが承認され発効した場合、全額をまず独立した**3-of-5 AURORAトレジャリー・マルチシグ**で受領する。実装参加者はいずれも、このマルチシグの署名鍵を持たない。提案する管理者は、James "Blockjock" Meidinger、Christian Taylor、Elder Millennial、Wilco USDM、Eddie Dである。

初回以降の支払いには、直前のマイルストーン達成証拠の公開、管理者による審査、少なくとも3名の独立した管理者の承認を必要とする。Fairwayは実装用ウォレット、人員配置、外部委託、内部リソース配分を管理し、通常の実装経費について管理者の承認を必要としない。重大な利益相反は開示し、該当者は承認に参加せず、利益相反のない管理者で必要な閾値を満たす。

独立した資金使用監査は、M2の技術成果物の公開後と、M4期間中の最終完了手続前に実施する。中間監査はM2の技術受入れとは別に扱い、その完了を追加の受入基準とはしない。レビュー担当者は、実装参加者と管理者の双方から独立しているものとする。監査は、第11章に定める管理者残高、承認済み支払い、支援費用、再配分、遂行状況、重大な指摘事項を対象とし、Fairwayの内部費用の通常の照合を求めるものではない。承認された予算再配分は、次回のマイルストーン報告で開示する。

管理者は、重大な遂行上の問題や資金の不正使用がある場合、追加支払いを停止できる。取引は公開監査可能とし、第9章の条件に基づきプロジェクトが終了した場合は、管理者の保管下に残るADAを返還する。前払いは未完了の作業の受入れを意味せず、Fairwayの遂行責任を免除しない。管理者が保管するADAはステークプール運営者に委任せず、投票はAbstain（棄権）に委任する。

トレジャリー資金で開発するソフトウェア、標準、リファレンス実装は**Apache License 2.0**で公開する。
