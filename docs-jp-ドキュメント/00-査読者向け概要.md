# 審査者向け概要

**提案書第3版に準拠。** Auroraは、Cardanoの信用市場に共通のオープン基盤を約**5か月**、**4つのマイルストーン**で整備するため、**940,000 ADA**を申請する。

## Cardanoトレジャリー資金の対象

互換性のある融資実装を横断して、独立した融資リクエストUTxOを記述、インデックス化、発見、フィルタリング、検証し、評価しやすくする標準とソフトウェアを構築する。

資金対象には、メタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、オープンAPI、フィルタリング・クエリ機能、資本提供者プロファイル標準、リファレンスクエリライブラリ、開発者ツール、リファレンス実装、技術文書、テストネット技術デモンストレーション、独立したセキュリティ・法務レビューと資金使用の監査・監督が含まれる。

Auroraは、融資の組成、融資原資の保管、資金提供対象の決定を行わない。基礎となる融資実装が資金提供と決済を担い、Auroraは、その周囲に再利用可能な市場基盤を提供する。

## 予算

| 区分 | ADA |
| --- | ---: |
| 中核インフラストラクチャ開発 | **800,000** |
| レビュー・ホスティング・技術予備費 | **140,000** |
| **合計** | **940,000** |

参照価格を1 ADA当たり0.20米ドルとした参考換算額は、合計188,000米ドルである。申請通貨はADAであり、成果物は為替変動ではなく、承認済み範囲とマイルストーンの完了によって定義する。

## マイルストーンと審査証拠

| 段階 | 時期 | ADA配分 | 主な確認事項 |
| --- | --- | ---: | --- |
| M1：仕様・アーキテクチャ | 1か月目 | **140,000** | 中核仕様、アーキテクチャ、初期API・クエリ設計の公開 |
| M2：中核機能の構築 | 2～3か月目 | **320,000** | テストネットでの稼働、API・検証機能、独立した中間支出・照合レビュー |
| M3：統合・技術デモンストレーション | 4か月目 | **290,000** | リファレンス実装、クエリ、公開ツールと文書による主要処理の再現性 |
| M4：独立レビュー・公開 | 5か月目 | **190,000** | 必須レビュー・最終資金使用監査、Apache License 2.0での公開、第三者による展開・運用 |
| **合計** | **約5か月** | **940,000** | |

累積支出上限は、開始時の**140,000 ADA**、M1承認後の**460,000 ADA**、M2承認後の**750,000 ADA**、M3承認後の**940,000 ADA**と段階的に引き上げる。M4完了時に最終照合と報告を行う。各段階の正式な完了条件は[第7章](07-マイルストーンと成功基準.md)に記載する。

## 遂行体制とガバナンス

Fairwayが主導実装者兼調整者、Sundialが技術協力者、Fallen Icarus (Rusty)が技術アドバイザー兼アーキテクチャのレビュー担当者を務める。

全額を独立した**3-of-5 Auroraトレジャリー・マルチシグ**に保管し、実装参加者はいずれも署名鍵を持たない。提案する管理者は、James "Blockjock" Meidinger、Christian Taylor、Elder Millennial、Wilco USDM、Kriss Bairdである。

次の累積支出上限への移行には、達成証拠の公開、管理者による審査、3-of-5の承認を必要とする。重大な利益相反は開示し、該当者は承認に参加せず、利益相反のない管理者で必要な閾値を満たす。

独立した資金使用の監督には、M2後の中間支出・照合レビューとM4後の最終監査を含める。レビュー担当者は、実装参加者と管理者の双方から独立しているものとする。予備費の使用には、書面による理由説明、管理者の承認、次回マイルストーン報告での開示を必要とする。

取引は公開監査可能とし、第9章の条件に基づきプロジェクトが終了した場合は未使用ADAを返還する。支出前の保管ADAはステークプール運営者に委任せず、投票はAbstain（棄権）に委任する。

トレジャリー資金で開発するソフトウェア、標準、リファレンス実装は**Apache License 2.0**で公開する。
