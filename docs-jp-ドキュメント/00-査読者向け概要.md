# 査読者向け概要

Auroraは、Cardanoにおける機関信用市場のオープン基盤を約**5か月**、**4つの実装マイルストーン**で提供するため、**1,000,000 ADA**を請求する。

## Cardanoトレジャリー資金の対象

資金は、メタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、オープンAPI、フィルタリング・クエリ、資本提供者プロファイル標準、リファレンスクエリライブラリ、開発者ツール、リファレンス実装、文書、テストネット技術デモンストレーション、独立したセキュリティ・法務・資金使用レビューという再利用可能な公共基盤に限定する。

融資原資、商用融資パイロット、借り手展開、SACCOオンボーディング、ステーブルコイン変換、法定通貨決済、実融資実行には充当しない。

## 履行とガバナンス

Fairwayが主任実装者兼調整者、Sundialが技術協力者、Fallen Icarus (Rusty)が技術アドバイザー兼査読者を務める。全額は、実装参加者から独立したJames "Blockjock" Meidinger、Christian Taylor、Elder Millennial、Wilco USDM、Kriss Bairdが管理する専用の**3-of-5 Auroraトレジャリー・マルチシグ**で保管する。支出は、証拠の公開と審査を経たうえで、該当する累積マイルストーン上限の範囲内に限り進める。M2後に独立した中間支出・照合レビューを、M4後に最終的な独立資金使用監査を実施する。取引は公開監査可能とし、第9章の条件により終了した場合は未使用資金を返還する。
