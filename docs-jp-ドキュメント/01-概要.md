# 1. 概要

## 提案の要点

| 区分 | 概要 |
| --- | --- |
| **トレジャリーへの資金申請額** | **940,000 ADA** |
| **実施期間** | 約**5か月** |
| **目的** | Cardanoの信用市場に共通のオープンソース市場基盤を整備し、互換性のある融資実装を横断して信用機会を発見、フィルタリング、検証し、評価しやすくする |
| **主要成果物** | メタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、フィルタリング・クエリツール、オープンAPI、資本提供者プロファイル＋リファレンスクエリライブラリ、開発者ツール＋リファレンス実装、文書＋独立レビュー |

## 提案概要

CardanoのeUTxOモデルでは、すべての融資活動を流動性プールに集約することなく、個々の信用機会を独立したオンチェーン金融オブジェクトとして扱える。本提案における**融資リクエストUTxO（Loan Request UTxO）**とは、互換性のある融資インフラストラクチャによって作成され、個別の資金要請または信用機会を表すUTxOを指す。

この取引ベースの構造はオープンな信用市場の基礎になる。しかし、決済機能だけでは、一体として機能する市場は成立しない。資本提供者やアプリケーションには、機会を記述し、複数の実装を横断して発見し、関連基準でフィルタリングし、検証情報を評価し、関連情報を継続的に把握するための一貫した手段が必要である。

Auroraは、その共通市場レイヤーを提供する。

Cardanoの他の基盤技術と同様に、Auroraは、複数のプロトコル、アプリケーション、資本提供者がエコシステム全体で採用・運用できる共通標準とツールとして設計される。

標準化されたメタデータにより、融資リクエストUTxOに機械可読な市場情報と検証参照を付加できる。Auroraディスカバリーエンジンは、それらの機会をインデックス化し、オープンな発見・フィルタリング用インターフェースで公開する。検証フレームワークにより、互換アプリケーションや資本提供者は、付加された証明や検証参照を各自の要件に従って評価できる。

Auroraは基礎となる融資プロトコルを置き換えず、融資の組成、融資原資の保管、資金提供対象の決定も行わない。融資の実行は互換性のある信用市場インフラストラクチャが担う。Auroraは、その融資契約を取り巻くオープン標準とソフトウェアを提供し、独立して存在する機会を共通基盤上で発見、フィルタリング、検証できるようにする。

したがって、トレジャリー資金による実装では、本提案で定める共通の技術基盤の構築と検証に注力する。

## 中核となる公共成果物

トレジャリー資金により、再利用可能な共通の公共成果物を提供する。

- Aurora互換の信用機会と関連メタデータ参照を記述する**メタデータ標準**。
- 機関属性、適格性、コンプライアンスその他の証明ベースの情報を付加・評価する**検証フレームワーク**。
- 互換性のある融資リクエストUTxOをインデックス化し、標準化された市場情報を公開し、関連ライフサイクルを可視化する**Auroraディスカバリーエンジン**。
- 標準化された属性と公開基準に従って機会を特定する**フィルタリング・クエリツール**。
- Aurora互換の信用機会、メタデータ、検証情報、関連ライフサイクル情報にアクセスするための**オープンAPI**。
- 資本提供者の要件を表現し、再利用可能な市場クエリへ変換する**資本提供者プロファイル＋リファレンスクエリライブラリ**。
- 互換アプリケーションによるAuroraとの統合方法を示す**開発者ツール＋リファレンス実装**。
- 独立した実装・運用を支える**文書＋独立レビュー**。資金対象となるインフラストラクチャの範囲内で、セキュリティ・法務レビューを実施する。

実装の最終段階では、一連の処理を通して検証する技術デモンストレーションとオープンソース公開を行う。

## コンソーシアムと実施体制

Auroraは、1つの統合された実装として提供する。

**Fairway**は主導実装者兼プロジェクト調整者として、資金対象となる作業全体の遂行と統合に責任を負う。

**Sundial**は、資本提供者向け標準、発見・フィルタリング仕様、リファレンスクエリ、API設計、相互運用性に関連する分野で技術的に貢献する。

**Fallen Icarus (Rusty)**は技術アドバイザー兼レビュー担当者として、Cardanoの取引ベースの信用市場モデル、融資リクエストUTxOの設計、eUTxO固有の実装上の検討事項に関するアーキテクチャの専門知識を提供する。

トレジャリーは、組織ごとの個別作業ではなく、Aurora共通の公共成果物に資金を提供する。コンソーシアムの協力者やアドバイザーによる貢献も同じ実装の一部であり、別個の資金保管構造やガバナンス系統を設けるものではない。

## ガバナンス上の保護措置

配分全額の**940,000 ADA**は、独立したCardanoエコシステムの代表者のみが管理する専用の**3-of-5 Auroraトレジャリー・マルチシグ**に保管する。

Fairway、Sundial、Fallen Icarusその他の実装貢献者は、トレジャリーの署名鍵を保有しない。すべてのトレジャリー取引には、独立署名者5名のうち3名以上の承認が必要である。

実施は本提案で定める4つのマイルストーンに従って進める。Fairwayは、支出が該当する累積マイルストーン上限を超えて進む前に、必要な達成証拠を公開する。Auroraトレジャリー管理者は、その証拠を承認済みの完了基準に照らして審査する。ウォレットと取引は実装期間を通じて公開監査可能とし、第9章の条件に基づきプロジェクトが終了した場合は未使用資金を返還する。

## オープンなエコシステムへの確約

Auroraは、既存および将来のCardano融資実装を置き換えることなく補完する。

インフラストラクチャは、プロトコルに依存せず、モジュール式で、任意に利用できるよう設計する。標準、ディスカバリーエンジン、インターフェースは、異なる融資実装、検証技術、アプリケーションで採用・運用できる。

トレジャリー資金で開発するすべてのソフトウェア、標準、リファレンス実装は**Apache License 2.0**で公開する。組織や開発者は、その条件に従い、成果となるインフラストラクチャを利用、運用、変更、拡張、商用化できる。

トレジャリー資金によって長期的に残る成果は、将来の融資プロトコル、アプリケーション、検証提供者、資本提供者がその上に構築し、拡張できる再利用可能なCardano市場基盤である。
