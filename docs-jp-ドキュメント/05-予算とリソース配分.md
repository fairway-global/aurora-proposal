# 5. 予算とリソース配分

本トレジャリー資金引出しは、Auroraのオープンな信用市場インフラストラクチャを5か月で提供するため、**1,000,000 ADA**を請求する。

改訂予算は、ソフトウェア開発、技術標準、テスト、文書、独立レビュー、ホスティングおよび公開プロジェクト遂行に充当する。融資流動性、商用パイロットの実行、SACCOオンボーディング、ステーブルコイン変換、決済業務は含まない。

資金は、コンソーシアム構成員間の内部的な実装資源配分ではなく、承認された公共インフラストラクチャの提供に必要な作業に従って配分する。

| 配分 | ADA | 概算米ドル\* | 主な範囲 |
| --- | ---: | ---: | --- |
| 中核インフラストラクチャ開発 | **800,000** | **$152,000** | メタデータ・検証標準、Auroraディスカバリーエンジン、API、フィルタリング機能、開発者ツール、リファレンス実装、資本発見・配分コンポーネント、技術デモンストレーション、文書、プロジェクト遂行 |
| 共通レビュー、ホスティング、技術予備費 | **200,000** | **$38,000** | 独立セキュリティ・法務レビュー約**80,000 ADA**、独立したCardanoトレジャリー資金使用の監査・監督**30,000 ADA**、インフラストラクチャのホスティング・技術運用**40,000 ADA**、承認済みAurora範囲内の技術予備費**50,000 ADA** |
| **合計** | **1,000,000** | **$190,000** |  |

\* **1 ADA = US$0.19**の参照価格による例示的な値。

米ドル額は提案規模の理解を助ける目的に限って示す。請求通貨はADAであり、成果物はその後のADA/USD為替変動ではなく、範囲とマイルストーン完了によって定義される。

予算は個々の貢献者またはコンソーシアム構成員への報酬ではなく、公共成果物の作成責任を表す。実装資源の内部配分は主任実装者が管理し、資金対象範囲、マイルストーン要件、公共成果物を変更しない。すべての対象ソフトウェア、標準、リファレンス実装はApache License 2.0で公開する。

## 中核インフラストラクチャ開発

**800,000 ADA**は、第4章で定義した公共インフラストラクチャ、すなわちメタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、インデックス化・発見・フィルタリング、オープンAPI、開発者ツール、リファレンス実装、資本提供者プロファイル標準、発見・フィルタリング仕様、リファレンスクエリライブラリ、市場発見APIの設計・実装、軽量SDKまたは統合例、技術・統合文書、テストネット技術デモンストレーション、公開準備、調整・進捗報告に充当する。

成果物は個々の構成員ではなく本提案に帰属し、Fairwayが率いる統一実装計画の下で、必要に応じてコンソーシアム協力者が技術貢献する。

中核インフラストラクチャ開発の配分は、第4章および第7章に定める成果物とマイルストーン成果に照らして監視する。承認済みの履行分野間で配分の使途を重大に変更する場合は、マイルストーン報告を通じて開示する。

この配分は、商用融資、SACCOオンボーディング、融資原資、決済業務、私募資本形成、機関投資家からの資金調達、収益目的の展開には充当しない。

## 実装責任

Fairwayは主任実装者として全体の履行に責任を負い、エンジニアリング、標準策定、技術統合、文書、テスト、外部レビュー、マイルストーン、公開報告を調整する。必要に応じてコンソーシアム協力者その他の承認済み貢献者を調整できるが、対象範囲全体の履行責任は維持する。すべてをFairway要員だけで実装するという意味ではなく、Cardanoトレジャリーは貢献者間の所定の分業ではなく完成した公共インフラストラクチャとマイルストーンに資金を提供する。

## コンソーシアムの技術協力

Sundialは、統一されたAurora実装内の戦略的技術協力者として、資本提供者要件とAurora互換市場情報の接続に関する資本提供者プロファイル標準、発見・フィルタリング仕様、リファレンスクエリライブラリ、市場発見API設計、軽量統合例、相互運用性レビューに貢献する。これらは他の対象インフラストラクチャと同じ条件でエコシステムに公開する。Sundialの役割に、Cardanoトレジャリー資金による資金調達、事業開発、機関投資家との関係管理、商用オンボーディング、資本配分は含まれない。

## 共通レビュー、ホスティング、技術予備費

**200,000 ADA**は、対象ソフトウェア・技術インターフェースの独立セキュリティレビュー、オープンなインフラストラクチャ・標準・想定運用モデルの独立法務レビュー、開発・テスト・技術デモンストレーションのホスティング、承認範囲内の予見困難な実装要件に対する技術予備費、および取引と報告支出・承認予算区分・マイルストーン支出上限との照合を含む**独立したCardanoトレジャリー資金使用の監査・監督**に充当する。

商用融資業務、実融資パイロットの規制対応、ステーブルコイン決済、融資原資の保管、対象成果物外の活動には充当しない。予備費の使用は承認済み提案範囲の履行に限定し、書面による理由説明とAuroraトレジャリー管理者の承認を必要とする。使用内容は次回の公開マイルストーン報告で開示する。未使用の予備費は未支出のCardanoトレジャリーADAとして扱い、本提案の通常の照合・返還規定に従う。

## 資源配分の原則

第一に、構成員の内部報酬ではなく公共成果物に必要なインフラストラクチャと支援作業に配分する。第二に、Fairwayが全体責任を維持し、協力者の技術貢献を同一計画に組み込む。第三に、外部支出は公共インフラストラクチャに直接関係する独立レビュー、Cardanoトレジャリー資金使用の監査・監督、ホスティング、技術予備費に限定する。第四に、融資原資または商用展開のための留保は一切ない。

主任実装者は、総請求額、対象範囲、マイルストーン要件、公共成果物を変更しない限り、完了に必要な内部実装資源を調整できる。したがって予算は第4章の公共成果物に直接対応し、資金提供期間後もCardanoに残るインフラストラクチャに支出を限定する。
