# 5. 予算とリソース配分

本トレジャリー資金引出しでは、Auroraのオープンな信用市場基盤を5か月で提供するため、**940,000 ADA**を申請する。参照価格を**1 ADA当たり0.20米ドル**とすると、約**188,000米ドル**に相当する。

予算は、本提案で定める技術標準、オープンソース・ソフトウェア、テスト、文書、独立レビュー、ホスティング、関連基盤の開発と提供を対象とする。

トレジャリー資金は、組織ごとの個別作業ではなく、本提案で定めるオープンなインフラストラクチャと公共成果物に配分する。

| 配分 | ADA | 概算米ドル | 主な範囲 |
| --- | ---: | ---: | --- |
| 中核インフラストラクチャ開発 | **800,000** | **$160,000** | メタデータ・検証標準、Auroraディスカバリーエンジン、API、フィルタリング機能、開発者ツール、リファレンス実装、資本ディスカバリーレイヤーの構成要素、技術デモンストレーション、文書、プロジェクト遂行 |
| レビュー・ホスティング・技術予備費 | **140,000** | **$28,000** | 独立したセキュリティ・法務レビューに約**60,000 ADA**、独立したトレジャリー資金使用の監査・監督に**20,000 ADA**、インフラストラクチャのホスティング・技術運用に**30,000 ADA**、承認済みAurora範囲内の技術予備費に**30,000 ADA** |
| **合計** | **940,000** | **$188,000** | |

米ドル額は、**1 ADA = 0.20米ドル**の参照価格で算出した参考値である。

米ドル換算額は、審査者が提案規模を理解するためにのみ示している。トレジャリー資金の申請通貨はADAである。成果物は、その後のADA/USD為替変動ではなく、対象範囲とマイルストーンの完了によって定義される。

予算は、個々の貢献者やコンソーシアム構成員への報酬ではなく、公共成果物を作成する責任に対応するものである。実装リソースの内部配分は主導実装者が管理し、トレジャリー資金の対象範囲、マイルストーン要件、公共成果物を変更するものではない。

トレジャリー資金で開発するすべてのソフトウェア、標準、リファレンス実装は、Apache License 2.0で公開する。

## 中核インフラストラクチャ開発

中核インフラストラクチャ開発に配分する**800,000 ADA**は、第4章で定義した公共基盤の実装に充当する。

対象には、次の作業が含まれる。

- メタデータ標準の開発。
- 検証フレームワークの実装。
- Auroraディスカバリーエンジンの開発。
- インデックス化、発見、フィルタリング機能。
- オープンAPI。
- 開発者ツール。
- リファレンス実装。
- 資本提供者プロファイル標準。
- 発見・フィルタリング仕様。
- リファレンスクエリライブラリ。
- 市場発見APIの設計・実装への貢献。
- 軽量な資本ディスカバリーSDKコンポーネント、またはリファレンス統合例。
- 技術文書と統合ガイダンス。
- テストネット技術デモンストレーション。
- オープンソース・リポジトリの公開準備とリリース。
- プロジェクトの調整と公開進捗報告。

これらの成果物は、個々のコンソーシアム構成員ではなく、本提案に属する。Fairwayが主導する統合実装計画の下で開発し、必要に応じてコンソーシアムの協力者が技術的に貢献する。

この配分の使用状況は、第4章と第7章に定める成果物とマイルストーン成果に照らして監視する。承認済みの実施分野間でリソース配分に重大な変更がある場合は、マイルストーン報告で開示する。

## 実装責任

Fairwayは主導実装者として、トレジャリー資金による作業全体の遂行に責任を負う。

エンジニアリング、標準策定、技術統合、文書、テスト、外部レビュー、マイルストーンの達成、公開報告を調整する。必要に応じてコンソーシアムの協力者や他の承認済み貢献者の技術貢献を調整できるが、資金対象となる範囲全体の遂行責任は維持する。

この体制は、すべての成果物をFairwayの人員のみで実装しなければならないことを意味しない。トレジャリーは、貢献者間の所定の分業ではなく、完成した公共基盤と関連マイルストーンに資金を提供する。

## コンソーシアムの技術協力

Sundialは、統合されたAurora実装の中で、戦略的な技術協力者として参画する。

資本提供者の要件とAurora互換の市場情報との接続に関連する、次のオープンソース構成要素を中心に貢献する。

- 資本提供者プロファイル標準。
- 発見・フィルタリング仕様。
- リファレンスクエリライブラリ。
- 市場発見APIの設計。
- 軽量な統合例と関連技術成果物。
- 関連する標準・インターフェースを横断した資本提供者との相互運用性のレビュー。

これらは本提案の共通技術成果物の一部として開発し、他のトレジャリー資金対象基盤と同じオープンソースの確約に従って、エコシステムに提供する。

## レビュー・ホスティング・技術予備費

**140,000 ADA**の配分は、基盤を責任を持って提供するために必要な、外部対応とプロジェクト全体の要件に充当する。

- 対象ソフトウェアと関連技術インターフェースの独立したセキュリティレビュー。
- 本提案の範囲内におけるオープン基盤、標準、想定運用モデルの独立した法務レビュー。
- 開発、テスト、技術デモンストレーションに必要なホスティング。
- 承認済みの基盤範囲内で生じる予見困難な実装要件に対応する技術予備費。
- トレジャリー取引を報告済み支出、承認済み予算区分、マイルストーン支出上限と照合することを含む、**独立したトレジャリー資金使用の監査・監督**。

対象は、承認済みAurora範囲に直接関連する外部レビュー、基盤運用、資金使用の監督、技術要件に限定する。

技術予備費の使用は承認済み提案範囲の遂行に限り、書面による理由説明とAuroraトレジャリー管理者の承認を必要とする。使用内容は次回の公開マイルストーン報告で開示する。未使用の予備費は未支出のトレジャリーADAとして扱い、本提案の通常の照合・返還規定に従う。

## リソース配分の原則

改訂後の配分は、次の3つの原則に従う。

- コンソーシアム構成員の内部的な報酬取り決めではなく、承認済みの公共成果物を提供するために必要な基盤と支援作業に資金を配分する。
- Fairwayが全体の遂行責任を維持し、必要に応じてコンソーシアムの協力者による技術貢献を同じ実装計画に組み込む。
- 外部支出は、公共基盤の提供に直接関連する独立レビュー、資金使用の監査・監督、ホスティング、技術予備費に限る。

主導実装者は、総申請額、資金対象範囲、マイルストーン要件、公共成果物を変更しない限り、承認済み作業の完了に必要な実装リソースの内部配分を調整できる。

したがって、この予算は第4章の公共成果物に直接対応し、資金提供期間が終わった後もCardanoで利用可能な基盤にトレジャリー支出を限定する。
