# Aurora 日本語版

Cardanoにおける機関信用市場向けオープン・インフラストラクチャ

Auroraは、信用市場の発見、フィルタリング、検証、評価のための再利用可能な公共インフラストラクチャを構築するため、Cardanoトレジャリーに**1,000,000 ADA**を請求する提案である。約**5か月**、**4つの実装マイルストーン**で提供する。

実装は**インフラストラクチャに限定**される。融資原資、商用融資パイロット、借り手展開、SACCOオンボーディング、ステーブルコイン変換、法定通貨決済、実融資の実行には資金を充当しない。

| --- | --- |
| トレジャリー請求額 | **1,000,000 ADA** |
| 提供期間 | 約**5か月** |
| マイルストーン | **4つの実装マイルストーン** |
| 主任実装者 | **Fairway** |

Cardanoトレジャリー資金の対象は、メタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、オープンAPI、フィルタリング・クエリ、資本提供者プロファイル標準、リファレンスクエリライブラリ、開発者ツール、リファレンス実装、技術文書、テストネット技術デモンストレーション、独立レビューである。

全額は実装参加者から独立した5名が鍵を持つ専用3-of-5マルチシグで保管する。追加支出は公開マイルストーン証拠と完了基準の審査を条件とし、残高・取引は公開監査可能とする。提案条件に基づき終了した場合は未使用資金を返還する。
