# AURORA 日本語版

Cardanoにおける機関信用市場向けオープン・インフラストラクチャ

本日本語版は、AURORAのトレジャリー提案書を基に、章の順序と提案内容を維持して翻訳したものである。

AURORAは、Cardanoの信用市場に共通のオープンソース基盤を整備するため、トレジャリーに**940,000 ADA**を申請する。約**5か月**、**4つのマイルストーン**で、互換性のある融資実装を横断した信用機会の発見、フィルタリング、検証、評価を支える標準とソフトウェアを提供する。

**開発状況：** AURORAは、本提案に基づく開発を開始できる状態にある。トレジャリー資金による開発はまだ開始していない。トレジャリー引出しガバナンス・アクションの承認と発効、およびFairwayによる初回の実装報酬の受領後に開始する。

## 資金対象と遂行条件

資金対象となる公共成果物には、**メタデータ標準、検証フレームワーク、AURORAディスカバリーエンジン、オープンAPIとフィルタリング機能、資本提供者プロファイル標準とリファレンスクエリライブラリ、開発者ツールとリファレンス実装、技術文書、独立したセキュリティ・法務レビュー**が含まれる。最終段階では、テストネット上で一連の処理を通した技術デモンストレーションとオープンソース公開を行う。

AURORAは、基礎となる融資プロトコルを置き換えず、融資の組成、融資原資の保管、資金提供対象の決定を行わない。資金提供と決済は、基礎となる融資インフラストラクチャが担う。

トレジャリー引出しが承認され発効した場合、配分全額を、まず独立した管理者が管理する専用の**3-of-5 AURORAトレジャリー・マルチシグ**で受領する。プロジェクト開始時からFairwayの指定実装用ウォレットへ実装報酬を前払いし、その後の支払いは直前のマイルストーンの受入れ後に行う。累積支払上限は**140,000 / 460,000 / 750,000 / 940,000 ADA**であり、実装報酬と支援費用の双方を含む。各上限額がそのままFairwayへの個別支払額を意味するものではない。

Fairwayは実装用ウォレットと内部リソースを管理し、通常の実装経費について管理者の承認を必要としない。管理者は、承認済みの範囲と総予算内で再配分を承認できるが、必須レビュー、監査、既存の支払義務に必要な資金を確保する。独立した資金使用監査はM2技術成果物の公開後とM4期間中の完了手続前に実施し、中間監査をM2技術受入れの追加条件とはしない。監査範囲は第11章に定める。重大な遂行上の問題や資金の不正使用がある場合、管理者は追加支払いを停止できる。管理者の保管下に残る資金には、第9章の返還規定を適用する。
