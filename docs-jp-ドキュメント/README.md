# Aurora 日本語版

Cardanoにおける機関信用市場向けオープン・インフラストラクチャ

本日本語版は、Auroraのトレジャリー提案書を基に、章の順序と提案内容を維持して翻訳したものである。

Auroraは、Cardanoの信用市場に共通のオープンソース基盤を整備するため、トレジャリーに**940,000 ADA**を申請する。約**5か月**、**4つのマイルストーン**で、互換性のある融資実装を横断した信用機会の発見、フィルタリング、検証、評価を支える標準とソフトウェアを提供する。

## 資金対象と遂行条件

資金対象となる公共成果物は、**メタデータ標準、検証フレームワーク、Auroraディスカバリーエンジン、フィルタリング・クエリツール、オープンAPI、資本提供者プロファイル＋リファレンスクエリライブラリ、開発者ツール＋リファレンス実装、文書＋独立レビュー**の8つである。最終段階では、テストネット上で一連の処理を通した技術デモンストレーションとオープンソース公開を行う。

Auroraは、基礎となる融資プロトコルを置き換えず、融資の組成、融資原資の保管、資金提供対象の決定を行わない。資金提供と決済は、基礎となる融資インフラストラクチャが担う。

配分全額は、実装参加者から独立した5名が署名鍵を持つ専用3-of-5マルチシグで保管する。次の累積支出上限へ進むには、マイルストーン達成証拠の公開と管理者による審査・承認を必要とする。M2後に独立した中間支出・照合レビューを、M4後に最終的な独立資金使用監査を実施する。残高・取引は公開監査可能とし、提案条件に基づきプロジェクトが終了した場合は未使用資金を返還する。
