# 9. ガバナンスと監督

Auroraは、焦点を絞ったインフラストラクチャ実装のため、単一かつ独立管理のCardanoトレジャリー保管構造を用いる。全**1,000,000 ADA**を、独立したCardanoエコシステム代表者のみが管理する専用の**3-of-5 Auroraトレジャリー・マルチシグ**に保管する。Fairway、Sundial、Fallen Icarusその他の実装貢献者は署名鍵を持たない。第7章の4マイルストーンに従い、Fairwayが証拠を公開してから該当累積上限を超える支出へ進み、全取引には独立署名者5名中3名以上の承認を要する。

## Auroraトレジャリー・マルチシグ

これを配分全額の唯一の保管ウォレットとし、承認済み支出に使用するまで独立した**3-of-5**管理下に置く。

実装コンソーシアム構成員は署名鍵を持たない。5名はCardanoトレジャリー・ガバナンス上、共同して**Auroraトレジャリー管理者**を務める。この呼称は別のガバナンス機関や保管構造を新設せず、3-of-5マルチシグを管理する同じ5名を指す。

管理者は、資金の保管、マイルストーン証拠の審査、承認範囲・上限内の支出承認、資金使用と成果進捗の監視、重大な履行問題時の支出停止、残高・取引の透明性維持、終了時の未使用資金返還に責任を負う。エンジニアリング管理、技術アーキテクチャ決定、貢献者選定、分業、成果物の所有・支配は行わない。

取引または判断に関する重大な利益相反は開示し、該当管理者は承認を棄権する。それでも非相反署名者により3-of-5閾値を満たさなければならない。

管理者が辞任、鍵アクセス喪失、恒久的不在となった場合、**既存マルチシグが3-of-5承認閾値を満たせる場合に限り**、残る管理者は別の独立Cardano代表者への交代を承認できる。新しい資格情報が必要な場合、同じ独立性と閾値を維持する代替3-of-5マルチシグへ未使用残高を移行できる。交代と新保管アドレスは移動前に公開する。

## マイルストーン監督

全額は同じマルチシグに留まり、別ウォレット間の移転は行わない。

| マイルストーン | ADA配分 |
| --- | ---: |
| M1：仕様・アーキテクチャ | **150,000** |
| M2：中核構築 | **350,000** |
| M3：統合・技術デモンストレーション | **300,000** |
| M4：独立レビュー・公開 | **200,000** |
| **合計** | **1,000,000** |

開始時の上限は150,000 ADA、M1承認後は累積500,000 ADA、M2承認後は800,000 ADA、M3承認後は1,000,000 ADAである。M4完了により最終照合・報告を行う。次の上限へ進む前に、(1)Fairwayが第7章所定の証拠を公開し、(2)管理者が完了基準と照合し、(3)3-of-5マルチシグで承認する。

審査は証拠に基づき実務的に行い、仕様、リポジトリ、ソフトウェア、文書、実証、独立レビュー成果が公開され、基準を合理的に満たすことを確認する。エンジニアリングの再現やAuroraの再実装までは求めない。資金は承認済みインフラストラクチャに限り、融資原資、商用融資、借り手資金、ステーブルコイン決済、無関係な会社支出には使用できない。

## 運用責任

Fairwayは主任実装者兼調整者として計画、コンソーシアム貢献、外部技術・専門サービス、証拠、公開報告、全体履行を調整する。Sundialは共通成果へ技術貢献し、Fallen Icarusは必要に応じて信用市場アーキテクチャと融資リクエストUTxOモデルをレビューする。すべて一つの統合実装であり、別予算、別保管、別ガバナンス系統を生じさせない。管理者は保管、支出、説明責任を監督するが日常実装を指揮しない。

## 透明性と報告

支出開始前にマルチシグアドレスを公開し、全取引をオンチェーンで公開監査可能にする。Fairwayは各マイルストーンにつき公開進捗報告を1件公表し、成果物へのリンク、完了基準との照合、累計支出、重大な問題・是正項目を記載する。最終報告は対象成果を承認済み成果物に対応付け、最終リポジトリと文書へリンクする。

承認支出前のADAはステークプール運営者に委任せず、適用されるCardanoトレジャリー・ガバナンス要件に従って既定の**Abstain**投票選択肢に委任した状態を維持する。

## 返還と是正

マイルストーンが重大に未完了の場合、管理者はFairwayの是正中、追加支出を停止できる。目標日から**60日後**も未完了で、独立署名者と満足できる是正計画に合意していない場合、停止を継続し、下記条件で終了へ進める。完了前に終了した場合、残る未使用ADAを適用される返還手続によりCardanoトレジャリーへ返還する。

承認済み作業について正当に発生した支出はプロジェクト支出として、公開報告と財務照合で計上する。個々の貢献者の変更は成果物またはFairwayの全体責任を変更しない。
