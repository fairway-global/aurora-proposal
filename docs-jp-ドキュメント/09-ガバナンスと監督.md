# 9. ガバナンスと監督

トレジャリー引出しが承認され発効した場合、配分全額の**940,000 ADA**を、まず独立したCardanoエコシステム代表者が管理する専用の**3-of-5 AURORAトレジャリー・マルチシグ**で受領する。

Fairwayは遂行責任を負うが、このマルチシグの署名鍵は保有しない。Sundial、Fallen Icarus、その他の実装貢献者も、管理者が保管する資金に対する署名権限を持たない。

管理者は、第7章に従って実装報酬の分割払いと支援費用の支払いを承認する。マルチシグからの各取引には、少なくとも3名の独立した署名者の署名を必要とする。実装報酬は、プロジェクト開始時からFairwayが指定する実装用ウォレットへ分割して支払う。その後の支払いは、直前のマイルストーンについて、承認済み完了基準に照らした審査を経て行う。

Fairwayは自社の実装用ウォレットと実装リソースを管理し、遂行に対する責任を維持する。独立監査は、第11章に定める資金提供の仕組みを対象とする。管理者の保管下に残る資金は公開監査可能とし、以下の返還規定に従う。

## AURORAトレジャリー・マルチシグ

AURORAトレジャリー・マルチシグは、承認された支払いが行われるまで資金を保管する。未払いの資金は、独立した**3-of-5マルチシグ管理**の下に置く。承認済みの支払日程に従って実装報酬をFairwayへ送金した時点で、その資金はこの保管構造から離れる。

トレジャリー・ガバナンス上、この5名の独立したマルチシグ署名者が、共同して**AURORAトレジャリー管理者**を務める。この呼称は、別個のガバナンス機関や追加の資金保管構造を作るものではない。管理者とは、3-of-5 AURORAトレジャリー・マルチシグを管理する同じ5名を指す。

管理者は、次の責任を負う。

- 未払いのトレジャリー資金の保管。
- 承認済み完了基準に照らしたマイルストーン達成証拠の審査。
- 承認済みの資金上限内での、実装報酬の分割払いと支援費用の支払いの承認。
- 第11章に定める記録と独立監査を通じた、資金使用と遂行状況の監視。
- 重大な遂行上の問題や資金の不正使用を示す証拠が生じた場合の、追加支払いの停止。
- 管理者が保管する残高と支払いに関する公開の透明性の維持。
- 返還規定に従った、管理者の保管下に残る資金の返還。

管理者は、エンジニアリングの管理、AURORAの技術アーキテクチャの決定、実装貢献者の選定、コンソーシアム参加者間の作業分担を行わず、トレジャリー資金で開発する成果物の所有権や支配権を取得しない。

提案された取引やマイルストーンの判断に関わる重大な利益相反は、開示しなければならない。利益相反のある管理者は該当する承認に参加せず、取引は、利益相反のない署名者によって必要な3-of-5の閾値を満たさなければならない。

重大な利益相反には、提案されたトレジャリー支払いや有償のプロジェクト業務に対して直接の金銭的利害を有する場合、または雇用主、支配下の法人、密接な商業上の関係を持つ関連組織を通じて重大な間接的金銭利害を有する場合が含まれる。

管理者が辞任した場合、署名鍵にアクセスできなくなった場合、恒久的に対応不能となった場合、残る管理者は、**既存のマルチシグが引き続き3-of-5の承認閾値を満たせる場合に限り**、別の独立したCardanoエコシステム代表者への交代を承認できる。交代に新しいマルチシグ資格情報の作成が必要な場合は、同じ独立性と署名閾値を維持する代替の3-of-5 AURORAトレジャリー・マルチシグに未使用残高を移行できる。署名者の交代と新たな保管アドレスは、資金移動前に公開する。

## マイルストーンの監督

マイルストーン計画は、第7章に従い、AURORAトレジャリー・マルチシグからの支払いを規定する。実装報酬はFairwayが指定する実装用ウォレットへ分割して送金する。未払いの資金は、引き続き管理者が保管する。

| マイルストーン | ADA配分 |
| --- | ---: |
| M1：仕様・アーキテクチャ | **140,000** |
| M2：中核機能の構築 | **320,000** |
| M3：統合・技術デモンストレーション | **290,000** |
| M4：独立レビュー・公開 | **190,000** |
| **合計** | **940,000** |

初回の支払いによりM1の開始に必要な資金を提供する。その後の各段階は、直前のマイルストーンの受入れ後に、第7章の累積支払上限の範囲内で資金を提供する。

初回以降の各支払いに先立ち、以下を実施する。

1. Fairwayが、第7章で求められるマイルストーン達成証拠を公開する。
2. AURORAトレジャリー管理者が、公開された成果物を承認済みの完了基準に照らして審査する。
3. 少なくとも3名の独立した管理者が、該当する支払いを承認する。

実装報酬は、次の段階で合意された作業を行うための前払いである。Fairwayに同額の内部支出の証明を求める実費精算ではない。

マイルストーン審査は、証拠に基づき実務的に行う。管理者は、関連する仕様、リポジトリ、ソフトウェア、文書、実証、独立レビューの成果が公開され、承認済み完了基準を合理的に満たしていることを確認する。エンジニアリング作業の再現やAURORAの独自の再実装まで求めるものではない。

トレジャリー資金は、本提案で定義された承認済みAURORA基盤の範囲とマイルストーン成果物にのみ使用できる。

## 運用責任

Fairwayは、主導実装者兼プロジェクト調整者としてAURORAの遂行に引き続き責任を負う。

実装計画、コンソーシアムの貢献、外部の技術・専門サービス、マイルストーン達成証拠、公開報告、承認済み範囲全体の遂行を調整する。

Sundialは、AURORA共通の成果物に関連する分野で技術的な実装への意見を提供する。Fallen Icarusは、基礎となる信用市場アーキテクチャや融資リクエストUTxOモデルについて、必要に応じてアーキテクチャのレビューや助言を提供できる。

これらの貢献は、1つの統合されたAURORA実装の一部であり、別個のトレジャリー予算、資金保管構造、ガバナンス系統を作るものではない。

AURORAトレジャリー管理者は、資金保管、支払い、マイルストーンに関する説明責任を監督する。Fairwayは、日々の実装、人員配置、外部委託、内部リソース配分を管理する。Fairwayの実装用ウォレットから支払う通常の実装経費について、管理者の承認は不要である。

## 透明性と報告

プロジェクト支出の開始前に、AURORAトレジャリー・マルチシグのアドレスを公開する。

すべてのトレジャリー取引は、オンチェーンで公開監査可能とする。

Fairwayは各マイルストーンにつき1件の公開進捗報告を公表する。各報告には次の内容を含める。

- 関連する公開仕様、リポジトリ、ソフトウェア、文書、レビュー資料へのリンク。
- 該当するマイルストーン完了基準に対する達成状況の要約。
- 受領した実装報酬、支援費用の支払額、管理者の保管下に残る残高。
- 重大な遂行上の問題や是正項目。

最終報告では、完成した資金対象の成果を承認済み提案の成果物に対応付け、最終的なオープンソース・リポジトリと文書へのリンクを提示する。

承認済みプロジェクト支出に使用する前にAURORAトレジャリー・マルチシグで保管するADAは、ステークプール運営者に委任せず、適用されるCardanoトレジャリー・ガバナンス要件に従って、定義済みの**Abstain（棄権）**投票選択肢に委任した状態を維持する。

## 返還と是正

マイルストーンが重要な点で未完了である場合、AURORAトレジャリー管理者は、Fairwayが指摘された不足に対処する間、追加の支払いを停止できる。

目標日から**60日後**も未完了で、十分な是正計画に合意できていない場合、追加支払いの停止を継続し、プロジェクトの終了へ進めることができる。

完了前にプロジェクトが終了した場合、管理者の保管下に残るすべてのADAを、適用されるトレジャリー返還手続によりCardanoトレジャリーへ返還する。

完了し受け入れられた作業に対する実装報酬は、合意された成果物に照らして評価し、Fairwayの実際の内部費用に基づいて再計算しない。前払いを行ったことは、未完了の作業を受け入れたことを意味せず、Fairwayの遂行責任を免除するものでもない。

個々の貢献者が変更されても、承認済みAURORA成果物やFairwayの全体的な遂行責任は変わらない。
